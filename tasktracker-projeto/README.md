# TaskTracker 📝

O **TaskTracker** é uma aplicação em linha de comando (CLI) desenvolvida em Python para gerenciar tarefas diárias de forma simples, eficiente e rápida.

---

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python 3.10+
* **Módulos Nativos:** `sys`
